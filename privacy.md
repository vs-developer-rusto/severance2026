Политика конфиденциальности
Приложение «Выходное пособие при сокращении 2026» (ru.svp.severance2026)

Редакция от 26.10.2026

1. Общие положения

1.1. Настоящая Политика описывает, какие данные обрабатываются при использовании мобильного приложения «Выходное пособие при сокращении 2026» (далее — Приложение) для Android.

1.2. Связь по вопросам персональных данных и конфиденциальности: vs_developer@inbox.ru.

1.3. Используя Приложение, вы подтверждаете, что ознакомились с настоящей Политикой. Если вы не согласны с условиями, пожалуйста, не используйте Приложение.

1.4. Приложение предназначено для ориентировочного расчёта выходного пособия и связанных выплат при сокращении численности или штата работников либо ликвидации организации. Расчёт выполняется на устройстве пользователя. У Приложения нет собственной регистрации, аккаунтов и облачного сервера для хранения ваших расчётов.

1.5. Результат расчёта — ориентир, а не официальный расчёт работодателя, бухгалтерии, службы занятости или государственного органа.

2. Какие данные обрабатываются

2.1. Данные, которые вы вводите для расчёта (например, среднемесячный заработок, выбранный горизонт выплат 1–3 месяца, доход с начала года при включённом ориентире НДФЛ).
Эти данные используются только для расчёта на вашем устройстве. Оператор не получает их на свой сервер и не хранит их вне вашего устройства.

2.2. История последних расчётов.
История сохраняется локально на устройстве (без облака и без аккаунта). Вы можете удалить её средствами Приложения (например, свайпом в списке истории) или удалив/очистив данные Приложения в системе Android.

2.3. Данные для показа рекламы.
В Приложении используется рекламная сеть Яндекс.Реклама (баннер и межстраничная реклама). Рекламный SDK может самостоятельно получать технические данные устройства, необходимые для показа и учёта рекламы (в том числе рекламный идентификатор устройства и иные технические параметры по правилам SDK). Обработка таких данных регулируется политикой конфиденциальности Яндекса:
https://yandex.ru/legal/confidential/

2.4. Список других приложений линейки.
Для блока «Ещё из линейки» Приложение может один раз за запуск загрузить публичный JSON-список продуктов (например, с GitHub Pages). В этот запрос не передаются суммы расчётов, ФИО и иные введённые вами данные — только обычный сетевой запрос к публичному файлу.

2.5. Покупки внутри Приложения.
Если вы оформляете покупку «убрать рекламу» через RuStore или Google Play, платёжные данные обрабатываются соответствующим магазином приложений. Оператор не получает и не хранит данные банковских карт.

2.6. Обращения в поддержку.
Если вы пишете на vs_developer@inbox.ru, обрабатываются адрес электронной почты и содержание обращения — только для ответа на ваш запрос.

3. Цели обработки

- выполнение расчёта на устройстве пользователя;
- хранение локальной истории расчётов;
- показ рекламы и измерение её эффективности (через рекламный SDK);
- отображение ссылок на другие приложения линейки;
- обработка покупок через магазин приложений;
- ответ на обращения в поддержку.

4. Передача данных третьим лицам

4.1. Оператор не продаёт персональные данные и не передаёт введённые вами суммы расчёта на собственный сервер.

4.2. Третьи стороны, которые могут обрабатывать технические данные в связи с работой Приложения:
- Яндекс (реклама) — при наличии рекламы в установленной версии;
- хостинг публичного JSON линейки (например GitHub Pages) — только для загрузки списка приложений;
- VK / RuStore и/или Google Play — при установке, обновлении и покупках через магазин.

4.3. Оператор может раскрыть информацию, если это требуется по закону Российской Федерации или по запросу уполномоченного органа в установленном порядке.

5. Хранение и безопасность

5.1. Данные расчётов и история хранятся на вашем устройстве. Срок хранения истории определяется вами (удаление записей или данных Приложения).

5.2. Оператор не контролирует безопасность вашего устройства. Рекомендуется использовать актуальные обновления ОС и не предоставлять устройство посторонним лицам без необходимости.

6. Данные детей

Приложение не предназначено для сбора персональных данных детей и не ориентировано на лиц младше 13 лет. Если вы считаете, что ребёнок передал нам данные через обращение на email, напишите на vs_developer@inbox.ru — обращение будет удалено.

7. Ваши права

Вы можете:
- не вводить данные, которые не хотите указывать;
- удалить локальную историю в Приложении или через настройки Android («Очистить данные» / удаление Приложения);
- отключить персонализацию рекламы в настройках Android (рекламный идентификатор), если такая опция доступна на устройстве;
- оформить покупку «убрать рекламу», если она доступна в вашей версии;
- написать на vs_developer@inbox.ru с вопросом об обработке данных.

8. Изменение Политики

Оператор может обновлять настоящую Политику. Актуальная редакция публикуется по адресу Политики конфиденциальности, указанному в карточке Приложения в магазине, и доступна в разделе «О приложении». Дата редакции указана в начале документа.
